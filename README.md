## About Me

I am Sanni Shazily Oladipupo. Data Science student at the University of Lagos, self-taught AI engineer, and a builder with a bias for execution over theory.

I started with a broken phone and a curiosity about how things work. That curiosity became code. The code became products. The products became wins. I have now shipped AI applications in healthcare, education, insurance, governance, and privacy tech, competed in and won 5 hackathons, co-founded a youth tech community with 1,000+ members, and I am still just getting started.

My work is anchored in one belief: technology built for Africa must solve Africa's real problems. Every project I build is a test of that conviction.

I go by **shazdtechbro** online.

## Projects

### AI and Machine Learning

| Project | Description | Stack |
|---------|-------------|-------|
| **Dermascan** | AI platform detecting and predicting skin cancers. Gives treatment suggestions in any language and connects users to dermatologists | Python, TensorFlow, React |

| **Lumina** | Adaptive AI learning platform that personalises education based on each student's learning style and interests. Won AI for Social Impact at 234 Project Hackathon | Next.js, AI/ML, PostgreSQL |
| **Veritas-AI** | AI insurance claim auditor using geomapping and EXIF data to detect fraud in minutes. Won AWS West Africa Hackathon | AI, Geomapping, FastAPI |
| **Optic-Gov** | AI and blockchain platform acting as a paying auditor for Nigerian infrastructure projects. Releases funds only when quality is verified | AI, Blockchain, Computer Vision |
| **Trust-Grid** | Privacy-first SDK engine that stores user data securely and exposes only required fields to organisations via API. Built for NDPR compliance | SDK, Privacy Tech, API |
| **Zlearn** | Interactive educational platform with virtual experiments and adaptive lessons designed to make learning more engaging for students | React, Python |
